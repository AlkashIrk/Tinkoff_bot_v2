# Алгоритмический бот

Проект представляет собой бот нацеленный на дневную торговлю по стратегии 
HODL (соответствует инвестиционной стратегии «купи и держи»)




Необходимо:
1. Завести бота в telegram
2. [Получить токен](https://tinkoff.github.io/investAPI/token) в личном кабинете [Тинькофф Инвестиции](https://www.tinkoff.ru/invest/settings/)
3. Настроить конфиг **сonfig.ini**


### Описание секций сonfig.ini

#### 1. [Folders]

* base_folder - расположение файлов БД
* backup_folder - расположение сохранения бекапов

####2. [Files]


* base_main - расположение основной БД

в данной БД хранятся токены пользователя, тикеры за которые отслеживаются торговым ботом

#### 3. [Options]

* login - логин пользователя
* backup_base - создавать ли бекап БД со сделками пользоватлеля (отправка файла в телеграм)
* token - токен для биржи Тинькофф Инвестиции
* sandbox_token - sandbox токен для биржи Тинькофф Инвестиции

#### 4. [Telegram]
* telegram_token - токен управления телеграм бота 
* telegram_id - ID пользователя в мессенджере телеграм
